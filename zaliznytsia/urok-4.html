ESP32 і телефон

Дроти й кнопки — це добре на столі, але в локомотив, що їде колією, дріт не протягнеш. Сьогодні знайомимось із мозком, який уміє говорити по радіо, і вперше керуємо фарою з телефона. Займе 1–1,5 години.

Знайомся: ESP32

ESP32 — теж контролер, як Arduino, тільки менший, швидший і з вбудованим Wi-Fi. Програмують його тією самою мовою й тими самими командами: pinMode, digitalWrite, delay — усе, що ти вже знаєш, працює.

Як телефон розмовляє з локомотивом

ESP32 сам роздає Wi-Fi, як роутер. Телефон під'єднується до цієї мережі й відкриває сторінку, яку показує ESP32. Натиснув кнопку на сторінці — телефон надіслав запит, ESP32 його отримав і ввімкнув фару. Спробуй:

Перша програма для ESP32

  1. Відкрий wokwi.com/projects/new/esp32. Тепер праворуч плата ESP32.
  2. Додай світлодіод і резистор 220 Ω. Резистор — до гнізда з підписом D4 або 4, довга ніжка світлодіода — до резистора, коротка — до GND.
  3. Впиши програму і запусти ▶.
// Урок 4, частина А: ESP32 вітається і блимає
const int FARA = 4;

void setup() {
  Serial.begin(115200);    // ESP32 розмовляє швидше, ніж Uno
  pinMode(FARA, OUTPUT);
  Serial.println("Привіт! Я ESP32, мозок локомотива.");
}

void loop() {
  digitalWrite(FARA, HIGH);
  delay(500);
  digitalWrite(FARA, LOW);
  delay(500);
}

Фара блимає, а внизу з'явилося привітання. Бачиш? Програма майже така сама, як в уроці 1. Змінилися тільки номер гнізда і швидкість Serial.

Частина Б · потрібна справжня плата ESP32

Керуємо фарою з телефона

Тут симулятор уже не допоможе: телефон має під'єднатися до справжньої плати. Цю частину робимо, коли прийде набір деталей.

1

Підготуй комп'ютер (разом з дорослим)

  1. Встанови Arduino IDE з сайту arduino.cc/en/software.
  2. Відкрий Tools → Board → Boards Manager, знайди esp32 і встанови пакет esp32 by Espressif Systems.
  3. Під'єднай плату кабелем USB. У Tools → Board вибери свою плату (наприклад, XIAO_ESP32C3 або ESP32 Dev Module), у Tools → Port — порт COM, що з'явився.
2

Збери схему на макетці

Так само, як у симуляторі: гніздо 4 (на XIAO воно підписане D2) → резистор 220 Ω → довга ніжка світлодіода, коротка ніжка → GND.

3

Програма: ESP32 роздає Wi-Fi і показує пульт

// Урок 4, частина Б: фара керується з телефона
#include <WiFi.h>
#include <WebServer.h>

const int FARA = 4;
WebServer server(80);      // «сайт» усередині ESP32
bool fara = false;

// Сторінка, яку побачить телефон
String storinka() {
  String s = "<!doctype html><meta charset='utf-8'>";
  s += "<meta name='viewport' content='width=device-width'>";
  s += "<style>body{font-family:sans-serif;text-align:center}";
  s += "a{display:block;margin:16px;padding:24px;font-size:26px;";
  s += "border-radius:12px;color:#fff;text-decoration:none}</style>";
  s += "<h1>Локомотив 1</h1><p>Фара: ";
  if (fara) {
    s += "УВІМКНЕНА";
  } else {
    s += "вимкнена";
  }
  s += "</p><a href='/on' style='background:#1f8f50'>Увімкнути фару</a>";
  s += "<a href='/off' style='background:#cf3d3d'>Вимкнути фару</a>";
  return s;
}

void vidkryly() {          // телефон відкрив головну сторінку
  server.send(200, "text/html", storinka());
}

void uvimknuty() {         // натиснули «Увімкнути»
  fara = true;
  digitalWrite(FARA, HIGH);
  server.send(200, "text/html", storinka());
}

void vymknuty() {          // натиснули «Вимкнути»
  fara = false;
  digitalWrite(FARA, LOW);
  server.send(200, "text/html", storinka());
}

void setup() {
  pinMode(FARA, OUTPUT);
  WiFi.softAP("Lokomotyv-1", "potyag123");   // назва мережі й пароль
  server.on("/", vidkryly);
  server.on("/on", uvimknuty);
  server.on("/off", vymknuty);
  server.begin();
}

void loop() {
  server.handleClient();   // слухаємо, чи не прийшла команда
}

Натисни в Arduino IDE кнопку Upload (стрілка →). Якщо завантаження зависло на «Connecting…», затисни на платі кнопку BOOT, поки не почнеться.

4

Під'єднай телефон або планшет

  1. У налаштуваннях Wi-Fi знайди мережу Lokomotyv-1, пароль potyag123.
  2. Відкрий браузер і введи адресу 192.168.4.1.
  3. Натискай кнопки. Фара на макетці слухається телефона!

iPhone може написати «Немає підключення до інтернету». Це нормально: інтернет тут і не потрібен. Натисни «Використовувати без інтернету» або просто залишайся в цій мережі.

Завдання конструктора

Завдання 1 можна зробити в частині А, решту — на справжній платі.

Привітання з іменем легко

Придумай ім'я своєму локомотиву й зроби так, щоб ESP32 вітався ним, а мережа Wi-Fi називалася так само.

Свій дизайн пульта легко

Зміни кольори кнопок, розмір літер і заголовок сторінки. Кольори записуються так: #1f8f50 — зелений, #2266cc — синій. Ти — дизайнер пульта!

Кнопка «Привітатися» середньо

Додай третю кнопку з адресою /hello: фара тричі блимає. Тобі знадобиться нова функція і ще один рядок server.on.

Вперед і назад складно

Додай червоний задній ліхтар на гніздо 5. Кнопки «Вперед» і «Назад»: при «Вперед» горить біла фара, при «Назад» — червона. Майже як у справжньому локомотиві.

Перевір себе

Навіщо ESP32 роздає власну мережу Wi-Fi?

Щоб локомотив працював будь-де, навіть без домашнього роутера й інтернету, наприклад коли вимкнули світло.

Що робить server.handleClient() у loop()?

Постійно перевіряє, чи не надіслав телефон нову команду. Якщо надіслав — викликає потрібну функцію.

Що таке 192.168.4.1?

Адреса ESP32 у його власній мережі, як номер будинку. За нею телефон знаходить сторінку пульта.

Для дорослого

  • Це спрощена версія прошивки локомотива, яка вже написана: там такий самий вебсервер, але з ручкою швидкості, плавним розгоном, контролем акумулятора й зупинкою при втраті зв'язку.
  • Ваш Windows-комп'ютер може попросити драйвер тільки для плат з окремим чипом USB (CH340, CP2102). ESP32-C3 і ESP32-S3 з вбудованим USB працюють без драйвера.
  • Пізніше локомотиви говоритимуть не з телефоном напряму, а через станцію. Тоді один пульт керуватиме всіма поїздами.
