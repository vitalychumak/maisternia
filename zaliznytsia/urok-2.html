Залізниця HO · Урок 2 із серії «Мозок локомотива»

Кнопка машиніста

Минулого разу фара блимала сама. Сьогодні нею керуватимеш ти: натиснув кнопку — фара загорілась, натиснув ще раз — згасла. Для цього контролер має навчитися слухати, а не тільки говорити. Займе 40–50 хвилин.

Вихід і вхід

У контролера є гнізда, які можуть працювати двома способами:

  • Вихід (OUTPUT) — контролер говорить: вмикає фару, мотор, звук. Це ти робив в уроці 1.
  • Вхід (INPUT) — контролер слухає: чи натиснута кнопка, чи проїхав поїзд повз датчик.

У справжньому локомотиві входи потрібні всюди: кнопки в кабіні машиніста, датчики на колії, датчик заряду акумулятора.

Спробуй: кнопка-перемикач

faraUvimknena = false

Контролер пам'ятає, чи ввімкнена фара, у змінній. Кожне натискання перемикає її: false (ні) ↔ true (так).

1

Відкрий свій проєкт з уроку 1

Якщо ти його зберіг у Wokwi — відкрий. Якщо ні, збери знову: світлодіод з резистором 220 Ω на гнізді 13, коротка ніжка в GND.

2

Додай кнопку

  1. Натисни «+» і знайди Pushbutton (кнопка).
  2. У кнопки чотири ніжки, але працюють вони парами: ліва верхня з'єднана з правою верхньою, ліва нижня — з правою нижньою. Натиснув — і верхня пара з'єдналася з нижньою.
  3. Одну ліву ніжку з'єднай із гніздом 2, другу ліву — з GND.

Резистор для кнопки не потрібен: контролер має свій, вбудований. Його вмикає слово INPUT_PULLUP у програмі.

3

Програма 1: фара горить, поки тримаєш кнопку

// Урок 2, програма 1: фара горить, поки натиснута кнопка
const int FARA = 13;
const int KNOPKA = 2;

void setup() {
  pinMode(FARA, OUTPUT);
  pinMode(KNOPKA, INPUT_PULLUP);  // гніздо 2 слухає кнопку
}

void loop() {
  if (digitalRead(KNOPKA) == LOW) {  // якщо кнопку натиснуто
    digitalWrite(FARA, HIGH);        // увімкнути фару
  } else {                           // інакше
    digitalWrite(FARA, LOW);         // вимкнути фару
  }
}

Запусти ▶ і натискай кнопку мишкою. Тримаєш — горить, відпустив — згасла.

Чому натиснута — це LOW? Вбудований резистор тримає гніздо в стані HIGH. Коли натискаєш кнопку, вона з'єднує гніздо з GND, і там стає LOW. Трохи навпаки, просто запам'ятай: натиснуто = LOW.

4

Програма 2: справжній перемикач

Машиніст не триматиме кнопку всю дорогу. Зробимо як у демо вгорі: одне натискання — увімкнути, наступне — вимкнути.

// Урок 2, програма 2: кнопка-перемикач
const int FARA = 13;
const int KNOPKA = 2;
bool faraUvimknena = false;        // змінна: чи горить фара (спочатку ні)

void setup() {
  pinMode(FARA, OUTPUT);
  pinMode(KNOPKA, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(KNOPKA) == LOW) {          // кнопку натиснули
    faraUvimknena = !faraUvimknena;          // ! означає «навпаки»
    if (faraUvimknena) {
      digitalWrite(FARA, HIGH);
    } else {
      digitalWrite(FARA, LOW);
    }
    delay(50);                               // чекаємо, поки контакти «заспокояться»
    while (digitalRead(KNOPKA) == LOW) { }   // чекаємо, поки кнопку відпустять
    delay(50);
  }
}

Навіщо while? Контролер дуже швидкий: поки твій палець натискає кнопку, loop() встигає пробігти тисячі разів і перемкнути фару тисячі разів. Тому ми чекаємо, поки кнопку відпустять. А delay(50) потрібен, бо справжні контакти кнопки при натисканні кілька мілісекунд «тремтять».

Це як у Scratch

Блок у ScratchВ Arduino
«Якщо … то … інакше»if (…) { … } else { … }
«Клавішу пропуск натиснуто?»digitalRead(KNOPKA) == LOW
«Чекати до …»while (…) { } — крутиться, поки умова правдива
Змінна «так/ні»bool faraUvimknena = false;
Блок «не»!

Зверни увагу: «дорівнює» в умові пишеться двома знаками ==. Один знак = означає «покласти значення в змінну».

Завдання конструктора

Познач галочкою те, що вийшло.

Дві кнопки легко

Додай другу кнопку на гніздо 3. Зелена кнопка вмикає фару, червона — вимикає. (Колір кнопки змінюється в її налаштуваннях у Wokwi.)

Лічильник натискань середньо

Зроби змінну int skilky = 0; і збільшуй її при кожному натисканні: skilky = skilky + 1;. Щоб побачити число, додай у setup() рядок Serial.begin(9600);, а після натискання — Serial.println(skilky);. Числа з'являться у вікні під платою.

Гудок-сигнал середньо

Поки тримаєш кнопку, фара швидко блимає (як попереджувальний сигнал). Відпустив — згасла.

Три режими складно

Одна кнопка перемикає по колу три режими: «вимкнено» → «фара горить» → «фара блимає» → знову «вимкнено». Підказка: замість bool візьми int rezhym = 0; і після кожного натискання збільшуй його, а коли стане 3 — повертай до 0.

Перевір себе

Яка різниця між OUTPUT і INPUT_PULLUP?

OUTPUT — контролер сам подає сигнал (вмикає щось). INPUT_PULLUP — контролер слухає, що відбувається на гнізді, і тримає його в HIGH, поки кнопка не з'єднає його з GND.

Що буде без while у програмі 2?

Фара перемикатиметься багато разів, поки тримаєш кнопку, і загориться чи згасне випадково.

Чим відрізняються = і ==?

= кладе значення в змінну. == перевіряє, чи два значення однакові.

Для дорослого
