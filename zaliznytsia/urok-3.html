Залізниця HO · Урок 3 із серії «Мозок локомотива»

Мотор і швидкість

Фару можна тільки ввімкнути або вимкнути. А поїзд має їхати то повільно, то швидко, плавно рушати й плавно гальмувати. Сьогодні дізнаєшся, як контролер, який уміє тільки «так» і «ні», керує швидкістю. Займе 45–60 хвилин.

Секрет: дуже швидке миготіння

Контролер не вміє подати «половину» напруги. Зате він може вмикати й вимикати мотор сотні разів за секунду. Якщо мотор увімкнений половину часу, він крутиться приблизно на половину швидкості. Це називається ШІМ (широтно-імпульсна модуляція). Колеса й мотор важкі, тому не встигають помітити миготіння.

Верхня лінія — мотор увімкнений, нижня — вимкнений. Посунь ручку і подивись, як змінюється ширина «сходинок». Вимкни плавний розгін — колесо стрибатиме, як іграшка. Увімкни — рушатиме, як справжній поїзд.

Чому не можна під'єднати мотор прямо до контролера

Гніздо контролера дає зовсім маленький струм, приблизно як для одного світлодіода. Моторові потрібно в десятки разів більше. Тому між ними ставлять драйвер мотора: контролер — це мозок, який командує, а драйвер — м'язи, які виконують. У нашому локомотиві буде драйвер DRV8833, маленька плата розміром з ніготь.

У симуляторі мотора немає, тому замість нього візьмемо світлодіод: його яскравість буде нашою швидкістю. Програма для справжнього мотора майже така сама.

1

Нова схема

Створи новий проєкт: wokwi.com/projects/new/arduino-uno.

  1. Світлодіод з резистором 220 Ω, але тепер на гніздо 9. Біля номера 9 на платі намальована хвилька ~: так позначені гнізда, які вміють ШІМ.
  2. Додай Potentiometer (крутилка). Це наша ручка контролера машиніста.
  3. У крутилки три ніжки: VCC → гніздо 5V, GND → GND, середня SIG → гніздо A0.
2

Програма 1: ручка керує швидкістю

// Урок 3, програма 1: ручка швидкості
const int MOTOR = 9;     // поки що світлодіод замість мотора
const int RUCHKA = A0;   // крутилка

void setup() {
  pinMode(MOTOR, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int pozytsiia = analogRead(RUCHKA);                  // від 0 до 1023
  int shvydkist = map(pozytsiia, 0, 1023, 0, 255);     // перерахувати в 0..255
  analogWrite(MOTOR, shvydkist);                       // ШІМ: 0 = стоп, 255 = повний хід
  Serial.println(shvydkist);
  delay(20);
}

Запусти ▶, натисни на крутилку й крути її. Світлодіод стає яскравішим або тьмянішим, а внизу видно число швидкості.

Нові команди. analogRead читає не «так/ні», а число від 0 до 1023 (наскільки повернута ручка). map перераховує одну шкалу в іншу. analogWrite вмикає ШІМ: число від 0 до 255 означає, яку частину часу гніздо ввімкнене.

3

Програма 2: плавний розгін, як у справжнього поїзда

Справжній поїзд важкий: він не може миттєво розігнатися чи зупинитися. Зробимо так, щоб швидкість наближалася до положення ручки потроху, крок за кроком.

// Урок 3, програма 2: плавний розгін і гальмування
const int MOTOR = 9;
const int RUCHKA = A0;
int potochna = 0;        // швидкість, з якою їдемо зараз

void setup() {
  pinMode(MOTOR, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int tsil = map(analogRead(RUCHKA), 0, 1023, 0, 255);  // куди хоче машиніст

  if (potochna < tsil) {
    potochna = potochna + 1;   // розганяємось на один крок
  }
  if (potochna > tsil) {
    potochna = potochna - 1;   // гальмуємо на один крок
  }

  analogWrite(MOTOR, potochna);
  Serial.println(potochna);
  delay(10);                   // більше число — повільніший розгін
}

Різко поверни ручку до кінця. Світлодіод розгоряється поступово, приблизно за 2,5 секунди. Саме так працюватиме наш локомотив.

Завдання конструктора

Познач галочкою те, що вийшло.

Важкий товарний поїзд легко

Зроби розгін утричі повільнішим, ніби поїзд везе 50 вагонів з вугіллям.

Гальма сильніші за двигун середньо

У справжнього поїзда гальма спрацьовують швидше, ніж він розганяється. Зроби так, щоб при гальмуванні швидкість зменшувалась на 3 кроки, а при розгоні збільшувалась на 1. Обережно: подумай, що буде, якщо potochna стане менше нуля.

Поштовх на старті середньо

Справжній мотор на дуже малій швидкості гуде, але не рушає. Зроби так: якщо ручка трохи повернута (ціль більша за 0, але менша за 40), швидкість одразу стає 40.

Аварійна зупинка складно

Додай кнопку з уроку 2. Натиснув — поїзд зупиняється одразу, без плавного гальмування (potochna = 0), і стоїть, поки ручку не повернеш на нуль. Така кнопка буде і на нашій станції.

Перевір себе

Що таке ШІМ простими словами?

Дуже швидке вмикання й вимикання. Чим довше «ввімкнено» в кожному миготінні, тим швидше крутиться мотор і яскравіше світить світлодіод.

Навіщо драйвер мотора?

Контролер дає занадто малий струм для мотора. Драйвер отримує команду від контролера й подає на мотор великий струм від акумулятора.

Що змінити, щоб поїзд розганявся швидше?

Зменшити число в delay або збільшувати potochna більшими кроками.

Для дорослого

  • Програма 2 — це спрощена версія розгону в прошивці нашого локомотива: там так само є «поточна» і «цільова» швидкість, а крок залежить від налаштувань розгону й гальмування.
  • На Arduino Uno ШІМ на гнізді 9 має частоту близько 490 Гц, тому справжній мотор на ньому тихо пищатиме. У локомотиві ми використаємо 20 кГц, цього вже не чути.
  • Коли прийде набір, програму можна перевірити з маленьким мотором 3–6 В через модуль драйвера DRV8833. Не під'єднуйте мотор напряму до гнізда Arduino.
